# P3-A3 Annual Calendar Sources — Iran 1405

The runtime application does not scrape calendar websites. Annual official/religious holiday data is reviewed, versioned and published as source data.

Primary annual authority:

- Calendar Center, Institute of Geophysics, University of Tehran
- 1405 official calendar: `https://calendar.ut.ac.ir/documents/2139738/7092644/Calendar-1405.pdf`

Independent cross-check:

- Time.ir annual events: `https://www.time.ir/event-year`

The University of Tehran Institute of Geophysics public channel announced that the 1405 calendar was published on `calendar.ut.ac.ir` and provided the same PDF reference.

At the 2026-09-05 verification, the annual holiday list used by FieldRep OS contains 26 unique official holiday dates. Every stored canonical date is additionally checked by the project's deterministic Persian-calendar engine.
